EvoTrees.jl

EvoTrees.jl is a library for fitting decision trees in Julia.

Gradient boosted tree regression

Here is an example:

julia> using JuMP, MathOptAI, EvoTreesjulia> truth(x::Vector) = x[1] <= 0.5 ? -2 : (x[2] <= 0.3 ? 3 : 4)truth (generic function with 1 method)julia> x_train = abs.(sin.((1:10) .* (3:4)'));julia> size(x_train)(10, 2)julia> y_train = truth.(Vector.(eachrow(x_train)));julia> config = EvoTrees.EvoTreeRegressor(; nrounds = 3);julia> predictor = EvoTrees.fit(config; x_train, y_train);julia> model = Model();julia> @variable(model, 0 <= x[1:2] <= 1);julia> y, formulation = MathOptAI.add_predictor(model, predictor, x);julia> y1-element Vector{JuMP.VariableRef}: moai_AffineCombination[1]julia> formulationAffineCombination├ 1.0 * BinaryDecisionTree{Float64,Float64} [leaves=3, depth=2]├ 1.0 * BinaryDecisionTree{Float64,Float64} [leaves=3, depth=2]├ 1.0 * BinaryDecisionTree{Float64,Float64} [leaves=3, depth=2]└ 1.0 * [2.0]├ variables [1]│ └ moai_AffineCombination[1]└ constraints [1]  └ moai_BinaryDecisionTree_value[1] + moai_BinaryDecisionTree_value[1] + moai_BinaryDecisionTree_value[1] -
